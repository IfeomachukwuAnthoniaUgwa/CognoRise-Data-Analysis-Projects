# Project 1: Retail Sales Analysis


## Overview
This project analyzes retail sales data using Microsoft Power Bi and Power Query.


## Objectives
- Analyze total revenue and quality sold.
- Calculate Average Order Value.
- Compare revenue across product categories.
- Examine high value orders and customer characteristics.

  
## Tools
- Microsoft Power Bi
- Power Query
- Microsoft Excel

  
## Deliverables
- Data Cleaning documentation
- Analysis and methodology
- Key insights
- Business recommendations
- Power Bi dashboard
