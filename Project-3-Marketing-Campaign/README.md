## Project 3: Marketing Campaign Performance Analysis

## Overview

This project analyzes marketing campaign performance using Microsoft Power BI. It focuses on campaign engagement, conversions, advertising spend, target audiences, and return on investment (ROI).

## Objectives

- Evaluate key marketing performance indicators.
- Compare conversions across marketing channels.
- Examine performance across target audiences.
- Analyze monthly conversion trends.
- Compare advertising spend with conversions.
- Evaluate ROI across marketing channels.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX, where required for the project calculations

## Dataset

The dataset contains marketing campaign records, including campaign identifiers, dates, marketing channels, audience information, clicks, impressions, conversion-related metrics, costs, and ROI.

## Dashboard Features

## The interactive dashboard includes:

- Total Impressions
- Total Clicks
- Click-Through Rate (CTR)
- Total Conversions
- Total Spend
- Performance by Channel
- Performance by Target Audience
- Monthly Conversion Trend
- Spend versus Conversions by Channel
- Return on Investment by Channel
- Channel slicer for interactive filtering

## Key Findings

Email recorded the highest displayed conversion value at approximately 1.49 million, followed by Website at approximately 1.48 million.

Facebook recorded the highest displayed ROI value of 5.02, followed by Website at 5.01. The differences across channels were relatively small.

These results provide a starting point for evaluating channel performance, campaign efficiency, and budget allocation.

## Recommendations

- Compare channel conversion performance with advertising costs.
- Monitor monthly conversion trends.
- Evaluate audience performance when planning campaigns.
- Use verified ROI and acquisition-cost calculations to inform budget decisions.

## Conclusion

This project demonstrates the use of Power BI to transform marketing campaign data into an interactive dashboard for performance monitoring and decision-making.
